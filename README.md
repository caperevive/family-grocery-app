# Family Grocery App

Phase 1 browser/local-storage app for tracking family grocery slips and household costs.

## Local Run

Open `index.html` in a browser, or use any simple static file server pointed at this folder.

## Phase 1 Notes

- Data is saved in the browser with `localStorage`.
- No Supabase or external database is connected yet.
- OCR runs in the browser through Tesseract.js from a CDN.
- Vercel can publish the static files directly from this folder.
